Network settings (advanced)

Some Q-Hub units report a placeholder network config (e.g. 255.255.255.255) that does not reflect their real operating address — that matches OTAQ's own app, not a bug here. Don't treat the query above as ground truth.

Set a new IP address

Changing this can make the device unreachable at its current address until it's re-addressed via physical/serial access. This has been verified against the protocol but not exercised on real hardware — double-check the address before applying.
